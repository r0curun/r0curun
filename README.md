# `./methodology`

I like to keep things simple:

```text
[01] recon
     └─ understand the target

[02] enumerate
     └─ identify attack surface

[03] analyze
     └─ validate the finding

[04] exploit
     └─ prove impact safely

[05] report
     └─ document & disclose
```

The objective isn't just to find something that breaks.

It's to understand:

**Why does it break?**

**What's exposed?**

**What's the impact?**

**How could it be fixed?**
